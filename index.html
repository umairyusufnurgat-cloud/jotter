Settings

🛡️ Cloud account — your notes in your own Google Drive, end-to-end encrypted

Sign in with Google and Jotter keeps a copy of your notebook encrypted inside your own Google Drive (a hidden app folder only Jotter can see). Your passphrase scrambles everything before it leaves this browser — Google only ever stores unreadable ciphertext, and there is no Jotter server. Open Jotter anywhere, sign in with the same Google account, enter your passphrase, and your notes are back. Don’t lose the passphrase — by design it cannot be reset or recovered by anyone. Read the privacy policy.

Not connected.

☁️ Sync — free private cloud via your GitHub

Your notes sync through a secret gist on your own GitHub account, so they follow you to every browser and phone. Create a token with the gist scope only — create one here — and paste it below. It’s stored only in this browser. Secret gists are unlisted (not encrypted) — don’t sync anything you wouldn’t keep on GitHub.

Lock this note

The note’s text will be encrypted with a PIN using your browser’s built-in crypto (AES-256-GCM, key derived via PBKDF2, 150,000 rounds) and stored encrypted everywhere — in this browser, in backups and in sync. The title and tags stay visible so you can still find it.

⚠️ If you forget this PIN the note cannot be recovered — there is no reset, by design.

Help & guide

1
Create your first note
Click New note (or press N). Give it a title, then write below — everything saves automatically as you type.
2
Write in Markdown
**bold** *italic* # Heading - list - [ ] task [link](url). Switch to Split view (Ctrl+E) to see it rendered live — and open New note ▾ → Markdown playground for a live tour of every feature.
3
Organise
Add tags above the editor (type a name + ↵), then filter by them in the sidebar. Pin 📌 or star ⭐ important notes. Search everything with /.
4
Link notes together
Type [[ and pick a note to insert a link to it. A dashed link creates the note when clicked — build your own wiki.
5
Keep a journal
Today’s journal creates a dated entry with a template. Write daily and watch the 🔥 streak grow on the button.
6
Keep your notes safe
Notes live in this browser. Use Backup for a JSON file you can keep anywhere, or set up ⛎️ GitHub sync in Settings so notes follow you to every device — free, through your own GitHub.
7
Install it as an app
In your browser menu choose Install Jotter (on mobile: Add to Home screen). It then opens like a native app and works fully offline.
8
Everything at your fingertips

Sidebar

New note — create a blank note (N)
New from template ▾ — journal, meeting, reading, project, or brain-dump templates
Today’s journal — dated entry with a journal template; the 🔥 streak appears after 2+ days in a row

#
Tag chips — click to filter by a tag; right-click to rename it or remove it from all notes
Folders — always visible in the sidebar (collapse them with the caret): create with the +, rename, open, or delete folders with the ⋮ menu on each row. File notes by dragging a card onto a folder, via right-click / long-press on a card, or More ▾ → Move to folder. The location bar above the notes list shows where you are
Notes / Calendar / Trash — switch the sidebar between your notes, a month calendar of your writing, and the trash (deleted notes rest 30 days). In Trash, Recover all and Delete all sit right at the top — and you can drag a note onto the Trash button to throw it away
Resize / hide sidebar — drag the sidebar’s right edge to resize it; double-click the edge, press Ctrl+\ or use the ☰ toolbar button to hide it entirely
Note graph — your notes as a map of [[wiki-links]] and {{embeds}}; drag, zoom and pan it, click a bubble to open the note
Linked notes — [[Title]] links to a note (type [[ for the picker), {{Title}} embeds it live in the preview, and the Linked from bar above the statusbar shows every note that points at the one you’re reading
Backup ▾ — JSON backup of everything, or export all notes as one Markdown file
Import ▾ — restore a backup or import .md files; you can also just drag & drop files onto the app

v1.15 — linked notes

  • 📑 Note embeds — type {{Note title}} on its own line and that note is rendered live inside your preview: a neat card with its title, an “open” shortcut, and the full rendered content. Great for pulling meeting notes into a project page, or a recipe into a meal plan. Type {{ and the note picker pops up, just like [[. Nested embeds work (safely, a couple of levels deep), locked notes stay locked, and a missing title is one click from being created
  • 🔗 Backlinks bar — when other notes link to the note you’re reading (via [[links]] or {{embeds}}), a “Linked from” bar appears above the status bar with a chip for every linking note — click one to jump there. Your notebook finally answers “what points here?”
  • 🔬 The graph sees embeds too — {{embeds}} now draw edges in the note graph, so all three ways of connecting notes ([[links]], {{embeds}}, tags) are first-class

v1.14 — folders, simplified

  • 📁 Folders live in the sidebar, always — no more switching to a separate Folders tab. Your folders sit right under the search & sort rows with live counts, one click away. Collapse the section with the caret if you want the space back
  • 👆 Drag & drop filing — grab any note card and drop it on a folder to file it. Drop it on Unfiled notes to pull it out of a folder, or on the Trash button to throw it away. The card highlights, the target glows — it’s tactile and instant (mouse drag; on touch, use the card’s ⋮ menu as before)
  • 📦 Recover all / Delete all in Trash — the Trash view now has a proper toolbar: restore everything in one click, or empty it with a clear confirmation dialog (the old “Empty trash” link was buried at the bottom of the sidebar)
  • 🧪 One confirmation language — the last double-click-to-confirm buttons (delete forever, disconnect sync) now use the same clear dialog as everything else
