Help & guide

1
Create your first note
Click New note (or press N). Give it a title, then write below — everything saves automatically as you type.
2
Write in Markdown
**bold** *italic* # Heading - list - [ ] task [link](url). Switch to Split view (Ctrl+E) to see it rendered live — and open New note ▾ → Markdown playground for a live tour of every feature.
3
Organise
Add tags above the editor (type a name + ↵), then filter by them in the sidebar. Pin 📌 or star ⭐ important notes. Search everything with /.
4
Link notes together
Type [[ and pick a note to insert a link to it. A dashed link creates the note when clicked — build your own wiki.
5
Keep a journal
Today’s journal creates a dated entry with a template. Write daily and watch the 🔥 streak grow on the button.
6
Keep your notes safe
Notes live in this browser. Use Backup for a JSON file you can keep anywhere, or set up ⛎️ GitHub sync in Settings so notes follow you to every device — free, through your own GitHub.
7
Install it as an app
In your browser menu choose Install Jotter (on mobile: Add to Home screen). It then opens like a native app and works fully offline.
8
Everything at your fingertips

Sidebar

New note — create a blank note (N)
New from template ▾ — journal, meeting, reading, project, or brain-dump templates
Today’s journal — dated entry with a journal template; the 🔥 streak appears after 2+ days in a row
Search — live search across titles, text and tags (/); matches are highlighted
#
Tag chips — click to filter by a tag; right-click to rename it or remove it from all notes
Notes / Calendar / Trash — switch the sidebar between your notes, a month calendar of your writing, and the trash (deleted notes rest 30 days)
Resize / hide sidebar — drag the sidebar’s right edge to resize it; double-click the edge, press Ctrl+\ or use the ☰ toolbar button to hide it entirely
Backup ▾ — JSON backup of everything, or export all notes as one Markdown file
Import ▾ — restore a backup or import .md files; you can also just drag & drop files onto the app

Editor toolbar

Sidebar toggle — show or hide the notes sidebar (Ctrl+\); on mobile it slides the sidebar in
Edit / Split / Preview — writing modes; Split shows the live-rendered result beside your text (Ctrl+E cycles)
Outline — lists every heading in this note; click one to jump to it
Focus mode — hide everything but your writing (Ctrl+., Esc exits)
Star — mark this note as a favourite
Pin — keep this note at the top of the list
Download — save this note as a .md file
Print — print or save as PDF with clean print styles
More — duplicate the note, copy its markdown, browse its version history, share it as a link, or move it to trash

In the editor

#
Tags — type a name and press ↵; click × on a chip to remove it
Checkboxes — tick tasks in the preview and the markdown updates itself
Paste image — Ctrl+V pastes screenshots straight into the note (auto-resized, stored locally); you can also drag image files in
Timestamp — Ctrl+; inserts the current date & time (great for journals and logs)
[[ ]]
Wiki-links — type [[ for autocomplete; click a link to open (or create) that note
Floating + — on mobile, quick new note from anywhere

v1.7 current

  • 🕒 Version history — Jotter snapshots your note automatically every ~10 minutes while you edit (More ▾ → Version history). Preview any version and restore it in one click — restoring keeps a snapshot first, so it’s always undoable
  • 🔗 Share a note as a link — More ▾ → Share as link copies a URL that carries the note inside it; anyone who opens it gets a copy in their Jotter. No account, no server — perfect for sending a note to your phone
