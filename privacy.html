Privacy Policy

Last updated: 4 September 2026 · applies to the Jotter web app at this address

The short version: Jotter has no servers, no accounts database, no analytics and no trackers. Your notes live in your browser. If you switch on the optional cloud account, an end-to-end-encrypted copy of your notebook is stored in your own Google Drive — we can never read it, and neither can anyone operating this website.

1. Who processes what

  • This website (a static page) — serves the app files. It collects nothing: no analytics, no cookies, no tracking pixels, no logs of yours.
  • Your browser (local storage) — all notes, folders, tags and settings are saved in your browser's localStorage on your device. They never leave it unless you explicitly use a sync or export feature.
  • Google (only if you enable the cloud account) — described below.
  • GitHub (only if you enable GitHub sync) — notes sync to a secret gist in your own GitHub account, using a token you provide. Jotter's authors have no access to it.

2. The cloud account and Google user data

The optional cloud account uses Google Sign-In and requests exactly one Google scope: https://www.googleapis.com/auth/drive.appdata — access to a hidden application folder inside your own Google Drive, which only Jotter can see.

  • What is stored: a single file containing your notebook, encrypted in your browser before upload with AES-256-GCM. The key is derived from a passphrase that never leaves your browser and is never uploaded, logged, or transmitted anywhere.
  • What Google stores: unreadable ciphertext. Your passphrase and decryption key are mathematically impossible for anyone else to obtain — there is no reset or recovery, by design.
  • What we can see: nothing. This app has no backend. No one operating this website can read, decrypt, or recover your notes.
  • Access tokens: sign-in produces a short-lived access token held in memory only (never written to disk), limited to the app-folder scope. Signing out revokes it immediately.
  • Your email address is shown on the settings screen purely so you can see which account you signed in with. It is not stored anywhere except your own browser.
  • Other Drive files: the app-folder scope grants no access to any other file in your Drive — it cannot read, modify, or see the rest of your Drive.

3. Deleting your data

  • Local notes: use Settings → Backup → export first if you want a copy, then trash your notes and empty the trash; browser data is cleared with your browser's site-data controls.
  • Cloud backup: Settings → Cloud account → Delete backup from Drive permanently deletes the encrypted file from your Google Drive. Signing out separately removes the app's access to your Drive.
  • Remove Drive access entirely: Google account → Security → "Third-party apps with account access" → Jotter → Remove access.

4. Locked notes

Notes you lock with a PIN are encrypted in your browser with AES-256-GCM before being saved anywhere — locally, in exports, in GitHub sync, or in the Drive cloud backup. The PIN is never stored or sent anywhere.

5. What we don't do

  • No analytics or telemetry of any kind
  • No advertising, no data sale, no data sharing with third parties
  • No account database — there is nothing to breach
  • No cookies (beyond your browser's own site data for the app itself)

6. Open source

Jotter is open source — you can read every line that runs in your browser, including exactly how encryption and sync work, in the GitHub repository.

7. Contact

Questions about this policy or the app: open an issue on the GitHub issue tracker.

Summary for reviewers The app requests the drive.appdata scope solely to store one encrypted file (the user's own notebook, encrypted client-side with a user-chosen passphrase) in the user's own Drive application data folder. No other Drive data is read or written. No data is transmitted to any server other than Google's Drive API endpoint, and the stored content is end-to-end encrypted by the client before upload.
